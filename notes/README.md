# Notes

Staging area for Elder and committee input on the **SBC Vocational Cooperative** / S&BSP.

## Adding Elder notes

1. Copy [`elders/_template.md`](elders/_template.md) to a new file named `YYYY-MM-DD-short-slug.md` (e.g. `2026-07-22-elder-smith-feedback.md`).
2. Fill in author, date, and sections that apply; leave unused sections blank or delete them.
3. Put unresolved items under **Open questions**.
4. If the source is a photo, scan, or PDF, save it under [`../assets/`](../assets/) and link it from the note.

You can also paste emailed notes into a new Markdown file in `elders/` — prefer the template structure when practical.
